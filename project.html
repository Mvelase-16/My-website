UniBITES

Campus Cafeteria Pre-Order Web Application

Project Overview

UniBITES is a web application designed to allow university students to pre-order meals from their campus cafeteria ahead of time. The system aims to reduce long queues, save students time between classes, and streamline order management for cafeteria staff.

Project Details

  • Team Name: ElevateTECH
  • Application Type: Web Application

Key Features

  • Browse cafeteria menu items online
  • Pre-order and schedule meal pickup times
  • Reduce queuing times during peak hours
  • Order tracking and management for cafeteria staff
